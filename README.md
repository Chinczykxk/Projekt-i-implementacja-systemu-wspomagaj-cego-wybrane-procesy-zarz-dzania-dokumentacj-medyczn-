# Projekt-i-implementacja-systemu-wspomagaj-cego-wybrane-procesy-zarz-dzania-dokumentacj-medyczn-
Aplikacja ma na celu usprawnienie przepływu informacji o pacjentach między placówkami medycznymi. Umożliwia szybkie ustalenie lokalizacji pacjenta oraz gromadzenie i przeglądanie dokumentacji medycznej w jednym miejscu, ograniczając straty czasu i usprawniając pracę personelu.
